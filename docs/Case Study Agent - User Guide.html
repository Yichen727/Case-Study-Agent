Open the app

Use the link above in your browser. If an access prompt appears, sign in with the email invited by the app owner. No local Python installation or API key entry is needed for the hosted app; the owner manages the API configuration.

Shared pilot workspace. The library, saved drafts and applied edits are currently shared rather than private to each employee. Coordinate before editing, restoring or deleting someone else’s work. Download files you need to keep.

1 / Search and choose cases

  1. In Search cases, describe the work you need. Include any essential production method, deliverable, outcome or exclusion.
  2. Click Search. Enter adds a new line in the brief.
  3. Review High Match results first. Expand Partial Match for related work with evidence gaps; open Matching evidence to check the reasons.
  4. Tick Select case, or use Select all High Match. Clear all selections removes choices kept from earlier searches too.

“Find AI-led content for a hospitality brand, with evidence that generative AI was used in production.”

Each original case slide is a separate choice. Two slides with the same case name can be different versions. Selections remain as you search and move between result pages within the current session; refreshing may reset them.

2 / Set the order and generate your deck

  1. Open Selected cases, or click the selected-case count above search results.
  2. Drag cases into the required order. Click a case’s × to remove it.
  3. Click Generate PPTX above the list. This confirms the current order and starts background generation.
  4. When ready, click Download PPTX, then open it in PowerPoint to check before sharing.
Your exported deck

Company template pages 1–4 → your selected cases → template page 5 and any later pages.
With the current five-page template, two cases produce seven slides.

Original slides remain editable. Metadata corrections alone do not rewrite their slide text. Regenerate after changing your selection, order or applied wording.

3 / Optionally rewrite selected body text

  1. Enter an Editing request in Selected cases and click Send request. Target a case by its current list number, or specify all selected cases.
  2. Compare Before / Preview and the supporting evidence. You can manually edit the preview.
  3. Click Apply changes to use it, or Discard to leave the applied version unchanged.
  4. Click Generate PPTX and download again. Applied text replaces only the supported body area; titles, media, layout and supported footer links stay in place.

“For cases 1 and 3, remove the section headings and rewrite each body as two paragraphs at about half its current length. Retain the documented outcomes.”

Numbers follow the list

“Case 2” means the second case in Selected cases, not original PPTX page 2. After reordering, use the new list numbers. Each request supports up to 10 slides, within a text-size limit.

Restore at any time

Restore original removes a case’s applied edits. Generate again to export its original body. This does not change files already downloaded or overwrite the source presentation.

Pending previews are not exported. Reordering invalidates an existing preview. Bodies with inline hyperlinks or no safe edit area remain unchanged with an explanation. Long edits may need shortening to fit the original body frame.

4 / Describe the project and create a draft

  1. Open Create case. In Describe your project, provide the client, services, pillar, project challenge, creative approach and actual results.
  2. Optionally use Upload Image to add 0–4 PNG or JPEG images, up to 10 MB each. Then click Create draft.
  3. Check the seven fields: Title, Client, Services, Pillar, Brief, Creative and Impact. Edit wording directly as needed.
  4. Use Additional details → Submit details to add facts or refine the wording. You can continue the conversation; Skip for now dismisses a missing-information prompt.
Keep results factual. Supply achieved outcomes and their evidence. If results are unavailable, say so. Missing information remains blank; a proposed goal must not become an achieved Impact. Review all AI-written text.

5 / Add images and an optional link

ItemHow it appears on the slide
ImagesFill slots 1–4 in the displayed order. Images are centred and cropped to fit, without stretching. Unused slots stay empty. Remove with ×; remove and re-upload to replace or reorder.
Website URLInclude it in your description or submitted details. Under Optional link, select it to export READ MORE HERE.
Video URLYouTube / Vimeo links are recognised. Choose Video to export WATCH VIDEO HERE. Other sites can be classified manually; video files are not embedded.
Multiple / no linksThe first candidate is selected automatically. Choose another, adjust Link type, or select No link. Only one footer link is exported.

6 / Save and export the single slide

Click Save draft to keep edits, or Generate PPTX to save and generate, then Download PPTX. Client and Services stay in the draft and are not printed on the slide.

Title: exported in uppercase, maximum 40 characters. Body: Brief + Creative + Impact total 120–250 English words, with no fixed split. Short drafts are allowed with an information warning; more than 250 words must be shortened before export.

This workflow exports one standalone slide. New cases are not yet added to the searchable library or combined directly with selected existing cases. Check image cropping, wording and layout in PowerPoint.

Retry and History

Retry requests new wording from the original notes and submitted details while protecting manual field edits and images. Generate a new PPTX after a successful retry.

The History icon opens saved drafts. Click a title to reopen; × permanently deletes that draft, its images and its generated files. Start new case keeps earlier drafts.

Import approved decks

If the library is empty, use Import presentations, choose local .pptx files (up to 500 MB each), and click Parse and save decks.

Download online decks to your computer first. Identical re-uploads reuse existing cases. All cases shows the library. Follow progress under Processing.

Review missing metadata

Open Needs Review, choose a case, correct the fields and click Save metadata. Other metadata contains the title, pillar and three body sections. Show all cases also allows corrections to complete records.

Confirmed means required fields are populated; it does not certify AI inference. Needs Review means something is missing or Unknown. Both can appear in searches and exports. Metadata completeness is separate from match quality.

Retry AI enrichment infers missing Client / Services from source text. Retry web metadata revisits existing case links. These retries operate on the source deck and preserve manual corrections; they do not invent missing Brief / Creative / Impact text.

No High MatchExpand Partial Match and inspect evidence gaps. Refine the brief without removing genuinely mandatory requirements.
Import / AI task failsRead Processing. For an invalid PPTX, save a valid copy in PowerPoint and re-upload. For an AI failure, retry or ask the owner to check service configuration.

Before you leave: download the PPTX files you need. Cloud-local storage is not a guaranteed archive. Clear finished tasks removes generated selected-case decks; coordinate with colleagues before using it in the shared workspace. Never paste API keys or passwords into project notes.
