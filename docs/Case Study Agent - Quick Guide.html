01

Add presentations

Upload an approved .pptx file in Import presentations and select Parse and save decks. Existing library cases can be searched straight away.

02

Find relevant work

Describe your brief, including must-haves or alternatives. Start with High Match; expand Partial Match and Matching evidence to check gaps.

03

Select & refine

Select cases, then open Selected cases. Drag to reorder or remove slides. Use Editing request to revise text, preview it and Apply changes.

04

Export your deck

Click Generate PPTX, then Download PPTX. Your editable deck follows the selected order and includes the company template. Generate again after edits.

05

Create a new case

Describe a project in Create case. Refine the draft, add up to four images and an optional link, then export one editable slide. Reopen saved drafts with History.

06

Browse & review

Use All cases to browse the library and Needs Review to complete missing metadata. Missing or unknown information remains visible for review.

Before sharing: Check the wording and downloaded deck in PowerPoint. Confirmed means metadata is complete; it does not independently verify AI inferences.
